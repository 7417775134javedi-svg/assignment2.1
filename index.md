Here is the complete code and step-by-step guide to complete Assignment 2.1: First HTML Page.

Step 1: Create the index.html File
Create a new file in your project folder named index.html and copy the code below into it. This file includes the required structure, headings, proper indentation, and HTML comments.

HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <!-- Metadata and Page Title -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
</head>
<body>

    <!-- Main Heading -->
    <h1>Welcome to My First Webpage</h1>

    <!-- First Subheading -->
    <h2>About Me</h2>
    <p>Hello! My name is [Your Name], and I am learning the fundamentals of web development.</p>

    <!-- Second Subheading -->
    <h2>My Favorite Hobbies</h2>
    <p>In my free time, I enjoy coding, reading tech blogs, and exploring new technologies.</p>

    <!-- Third Subheading -->
    <h2>Goals for This Course</h2>
    <p>By the end of this course, I want to build responsive and interactive websites from scratch.</p>

</body>
</html>
Step 2: Verify by Opening the Page in a Browser
Navigate to the folder where you saved your index.html file.

Double-click index.html (or right-click it, select Open with, and choose your preferred browser like Chrome, Firefox, or Edge).

Confirm that:

The browser tab displays the title "My First Webpage".

The main heading (<h1>) and all three subheadings (<h2>) render correctly with text underneath them.

Step 3: Submission Requirements
Depending on your instructor's specific instructions, your submission should include:

A browser screenshot showing the webpage open and rendering properly in your web browser.
